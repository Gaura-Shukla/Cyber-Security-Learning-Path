# Network Security / Nmap Lab



### \--Overview--



This repo contain hands on cybersecurity and packet analysis labs performed inside isolated virtual environment using Virtual box, wireshark, Kali Linux.





#### &#x20;Topic Covered



* Nmap Port Scan
* Ports
* SYN packets
* Open vs closed ports
* TCP handshake behavior
* Retransmissions
* DNS traffic analysis
* ICMP packet monitoring
* Wireshark packet capture





#### Tool Used



* Wireshark
* Nmap
* Tshark
* Kali Linux
* Virtual Box



#### 

#### Environment



* Internal virtual network
* Isolated Lab Setup
* Static IP Configuration



#### Learning Outcomes



* Nmap
* Port Scanning.
* Packet Inspection
* Traffic Monitoring
* Network Security
* PCAP generation and analysis





#### Disclaimer



All the activity were performed strictly inside isolated lab environment for defence cybersecurity learning purposes.
